# Club 社区平台 | 微服务架构与系统优化实战

**项目描述**：Club 社区平台是一个旨在提供高质量内容交互的系统。项目历经三期迭代，从传统的单体架构演进为基于领域设计（DDD）思想的微服务架构。本人作为核心开发，主导了系统微服务化重构、安全性方案升级、高性能模块优化及自动化运维体系的搭建。

---

## 🛠 技术栈
- **后端框架**：Spring Boot, Spring Cloud (Alibaba)
- **注册/配置中心**：Nacos
- **安全鉴权**：Sa-Token + Gateway + Redis
- **消息队列**：RocketMQ
- **持久层/建模**：元数建模 + EasyCode (MyBatis-Plus)
- **并发编排**：asyncTool
- **运维部署**：Docker, Jenkins, Shell, Linux

---

## 🌟 项目核心亮点与技术攻关

### 1. 架构演进：从耦合到领域驱动 (DDD)
* **微服务化拆分**：针对原有业务耦合问题，采用领域拆分思想将项目拆分为 **4 个核心微服务**，实现了业务解耦与职责分明。
* **接口解耦重构**：在三期迭代中，将三层架构进一步细化为 `api` 与 `server` 模块。`api` 层负责对外暴露接口，`server` 层专注内部业务逻辑，彻底解决了内外职责模糊的问题。

### 2. 安全治理：统一分布式鉴权方案
* **高效鉴权**：选取主流 **Sa-Token** 框架替代传统的 Spring Security，在保证权限控制粒度的同时，显著降低了上手难度和开发成本。
* **网关安全集成**：配合 **Gateway + Redis** 实现了统一的鉴权校验及分布式会话共享。在网关层落地了**全局异常处理机制**，确保了后端服务的健壮性。

### 3. 性能优化：高并发与数据一致性
* **消息驱动优化（RocketMQ）**：重构点赞功能，将原本仅依赖 Redis 的方案升级为 **RocketMQ 异步持久化**。有效解决了 Redis 在极端情况下数据丢失的问题，并实现了高峰值期间的削峰填谷。
* **线程编排优化（asyncTool）**：引入 `asyncTool` 对多线程代码进行精细化管理。通过线程编排实现了任务执行顺序的可视化解耦，提升了系统在复杂逻辑下的并发吞吐效率。

### 4. 代码设计：模式驱动与 SDK 封装
* **复杂逻辑解耦**：
    * 采用**工厂模式 + 策略模式**重构微信消息处理模块，支持多种消息类型的无缝扩展，消除了大量 `if-else`。
    * 采用**适配器模式**实现 OSS 对接，屏蔽了底层不同存储供应商的接口差异。
* **业务中台化**：抽取独立的微信微服务，完成微信对接回调与 SDK 的统一封装，沉淀出具备高度复用性的无业务干扰通用服务。

### 5. 工程效能：自动化部署与工具链
* **从 0 到 1 运维实战**：独立完成生产环境云服务器的搭建、依赖安装及系统调优。
* **CI/CD 落地**：针对多机器部署手动拖拽 jar 包的痛点，编写 **Shell 脚本** 配合 **Jenkins** 实现了自动化部署流程，部署效率提升数倍。
* **模型驱动开发**：利用元数建模配合 **EasyCode** 实现模型搭建与代码自动生成，大幅减少重复性编码工作，提升了 50% 以上的基础开发效率。
